# Pixel pets and pixel-me

Date: 2026-10-04. Status: spec, awaiting review.

A resident pixel cat that lives on every page, a rare stoat visitor, and a pixel version of the site owner at a desk. Project spot icons are a separate, later spec.

Approved art and its generators are in `docs/superpowers/specs/2026-10-04-pixel-pets/`. The spec refers to them as the reference set.

## Decisions already made

| Topic | Decision |
|---|---|
| Resident | A cat. A stoat is a rare cameo that interacts with it. |
| Cat style | The sleek style: natural proportions, small head, long tapered tail. The sitting idle in `styles/sleek/` is approved as drawn. |
| Cat walk | The hand-keyed walk in `walk-sleek/` is approved as drawn: 12 frames, 1320 ms, 1 px travel per frame. Walks are never generated by a leg rig. |
| Size | Sprites are drawn at 32x32 and shown at an integer scale, 2x by default. |
| Frames | 12 to 16 frames for loops. Fast one-shots (swat, startle) may use fewer if more frames make them feel slow. |
| Coats | Tuxedo, orange, black, shiny. One drawing, coats are palette swaps. All four ship. |
| Pixel-me | Long black hair falling behind the back, beard, friendly face, light skin, burgundy sweater over a collar. |
| Desk "AI" cue | Code scrolls on the laptop screen inside the sprite. A small neural net floats above the desk in site code. |

## Sprite format

Every sprite uses the Clawd JSON format: `w`, `h`, `palette`, `palettes` (variant name to letter overrides), and `animations` mapping a name to `{loop, frames: [{ms, px}]}`. `.` is transparent. Walks carry `travel` in px per frame, and the desk scene carries `catSlot: [x, y, w, h]`.

The generators in the reference set are Python scripts that emit this JSON. They move into the repo at `tools/sprites/` with their JSON output at `src/assets/sprites/*.json`. The JSON is checked in, so the site build never runs Python. The hand-typed leg drawings live in `legs.py`, which is why the generators are kept: editing a pose means editing the script and rebuilding.

## Renderer

One component, `<PixelSprite sprite clip palette scale flip onEnd />`, draws a clip to a `<canvas>`.

- It pre-renders each frame once per palette into an offscreen canvas, then blits, so a frame change costs one `drawImage`.
- `imageSmoothingEnabled = false`, and the scale is an integer multiplied by `devicePixelRatio` rounded, so pixels stay square.
- `flip` mirrors horizontally. The sit faces left and the walk faces right; the controller flips to match the direction of travel.
- A single `requestAnimationFrame` loop drives every mounted sprite on the page.

## The cat

### Mounting

The pet layer mounts in `App.tsx` beside `<AccessibilityPanel />`, outside the `.page-enter` wrapper. That wrapper carries a transform, which turns `position: fixed` into position relative to the wrapper, so a pet inside it would scroll away and replay the page-enter animation on every route change. The layer is `position: fixed`, `pointer-events: none` except on the sprite itself, and sits on the bottom edge of the viewport.

### Behavior

A small state machine in `src/lib/pet/cat.ts` picks the clip. Timers are given as starting values to tune by eye.

| Trigger | Cat does |
|---|---|
| Page untouched | idle, then groom after ~20 s, loaf after ~40 s, sleep after ~60 s |
| Cursor within ~200 px | turns its head toward it (look poses) |
| Hover on the cat | startle |
| Click on the cat | pounce or swat, chosen at random; about 1 in 5 clicks get ignored (an ear flick) |
| Route change or scroll | walks or runs to a new spot along the bottom edge, then sits |
| Return after sleep | wake (stretch, yawn), then idle |
| Rare, random | zoomies: runs the full width of the viewport and back |

### Micro-moments

These play in fixed places on a page, separate from the wandering cat. While one is on screen, the wandering cat hides so there are never two cats.

| Where | Clip | Component |
|---|---|---|
| 404 page | confused, loop | `src/routes/not-found.tsx` |
| Loading (the `Suspense` fallback, currently `null`) | chase_tail, loop | `App.tsx` |
| End of a blog post | happy (slow blink, tail up) | `post-signoff.tsx` |

### Animation list

Approved: idle, walk. To draw in the sleek style, hand-keyed, using the chibi draft (`chibi-suite-draft.json`) only as a motion reference: run, sit_down, loaf, sleep, wake, groom, look, swat, startle, pounce, chase_tail, confused, happy, zoomies (can reuse run). Each one is checked against the sitting idle side by side for mass and proportion before it is accepted.

## The stoat

The stoat is drawn in the same style and format, about 32x20, with two palettes: brown summer coat and white winter coat (the kärppä), both with a black tail tip. The winter coat shows from November to March.

Clips: bound (the arched-back lope), periscope (stands up, looks around, drops), war_dance, peek (head out of a gap).

Visits are scheduled per page view: a 1 in 6 chance by default, 1 in 3 in winter. A visit picks one script:

- It bounds across the bottom edge. If the cat is awake, the cat startles and may chase it off screen.
- It periscopes up from behind the footer and drops back down.
- It peeks out, and if clicked before it leaves, it war-dances.
- If the cat is out walking, the stoat takes the cat's spot until the cat comes back.

## Pixel-me

The reference sprite is `me/me.json`, approved: idle (16 frames), walk (16), and desk (42 frames, 8040 ms) on a 99x57 canvas. Defaults: the `sweater` outfit and the `light` skin palette. The other outfits and skin tones stay in the file but are not offered on the site.

The desk scene lives on `/about`. The cat sleeps in the desk's `catSlot` while it is on screen, and the wandering cat hides, by the same rule as the micro-moments.

### Neural net

A small graph of 5 or 6 nodes drawn on a canvas above the laptop, in the clear rows the sprite leaves at the top. Connections pulse while the desk clip is on a typing frame and settle during the sip, beard, and hair beats. The desk JSON marks typing frames with `"typing": true`, so the net reads that flag and does not keep its own timing.

## Settings panel

A small pet button opens a panel with:

- **Cat:** on or off.
- **Coat:** tuxedo, orange, black, shiny. The default is random on the first visit, then remembered.
- **Stoat:** off, rare, normal.

Settings persist in `localStorage` under `pet-prefs`, read and written inside try/catch so a blocked storage still renders the default. Labels go through `react-i18next` in all six locales.

## Motion and accessibility

- When `prefers-reduced-motion` is set, or the site's own `a11y-reduced-motion` class is on, the cat starts parked asleep in the corner and never wanders, and the stoat does not visit. The desk scene shows a single still frame.
- Sprites are decorative: `aria-hidden`, and the cat is not in the tab order. The settings panel is keyboard-operable.
- The pet layer never covers interactive content. It sits at the bottom edge with a small footprint, and a click that misses the sprite passes through.

## Out of scope

- Project spot icons (ØCLOAK, Engrammic, palpatine, hardware): the next spec.
- Pixel-me as a page walker. The walk clip exists, but nothing triggers it yet.
- Seasonal hats.

## Testing

- Unit tests for the cat state machine with fake timers: the idle chain, the micro-moment hide rule, and the reduced-motion start state.
- A sprite JSON test: every frame matches `w` x `h`, and every letter used in any frame exists in the base palette.
- Prerender test: the pet layer renders nothing on the server, so prerendered HTML does not change.
- Visual check in a browser on a page with the cat, `/about`, the 404 page, and one blog post.
